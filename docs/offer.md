# Предметный пилот TazaBatch

Сначала бесплатный синтетический просмотр одного фиксированного пакета code/label/city/qty и отказа частичного импорта. Формат реальной выгрузки,владелец процесса и текущие инструменты неизвестны.

Собственная предварительная оценка узкого согласованного процесса:5ч×5000₸=25000₸. Это не счёт/обязательство;сервер/домен/интеграции/настоящие данные отдельно. Код с ИИ-помощью,границы раскрываются;никаких обещаний экономии или клиентских результатов. Новых предложений/расходов/подписок/договоров нет.
