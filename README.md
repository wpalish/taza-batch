# TazaBatch 0.1

Собственный ограниченный процесс по направлению reference11 n8n: опубликованные упорядоченные шаги очистки вымышленной таблицы → неизменный отчёт before/after → один явный локальный импорт всего успешного output. Не n8n, не облачная автоматизация или интеграция.

## Запуск

Node.js >=24.15 <25; сторонних зависимостей нет. Задайте собственный WORK_ADMIN_PASSWORD14–200 символов; WORK_ADMIN_USER меняет имя первого администратора(по умолчанию admin). Env не сбрасывает пароль существующего пользователя.

```sh
PORT=8851 PUBLIC_ORIGIN=http://127.0.0.1:8851 npm start
npm test
```

HOST по умолчанию127.0.0.1, DATABASE_PATH=.data/workspace.sqlite. Не храните пароль/базу в Git. Для внешнего размещения нужны отдельные HTTPS/резервирование/эксплуатационная проверка; они не поставлены.

## Процесс

1. Admin создаёт цепочку с описаниями RU/KK, затем5–7 разных шагов с уникальными позициями1–20. Обязательны require_code/label/city, integer_qty и последний unique_code; опциональны trim_all/upper_code. Черновик может быть неполным.
2. Публикует точную версию и порядок. Версия не публикуется повторно даже после архива; поздняя правка не меняет историю.
3. Сотрудник вводит JSON-массив1–50 синтетических объектов. Ровно code,label,city,qty, все входные значения строки. До200знаков ячейка,qty до24;rawJSON до50000. Это не CSV/произвольная схема/файл настоящих клиентов. Повтор decodedключа/лишний/пропущенный столбец/вложение/типnumber илиnull получают сохранённый rejected отчёт.
4. Проверка выполняет упорядоченные шаги до первой ошибки включительно. Для каждого есть точные before/after и все ошибки этой стадии. Поздние шаги не выполняются;частичное преобразование не становится выходным набором. Никакой строки rejected-пакета импортировать нельзя.
5. Сохранение successful отчёта фиксирует весь output,версию/правила/ввод/автора/время,но ещё не импортирует. Только автор явно создаёт один отдельный локальный набор из всего output с основанием. Admin не обходит авторство;повтор/редактирование/частичная запись запрещены.

trim_all обрезает края строк; upper_code применяет Unicode toUpperCase без NFKC/перевода; require_* проверяет trim-непустой текст; integer_qty принимает только канонические десятичные цифры1–10000,не знак/ноль/ведущие нули/дробь/экспоненту. unique_code сравнивает точные конечные строки:без trim/upper регистр/пробелы различаются. qty становится number,остальные строки сохраняют результат операций. Код между разными наборами может повторяться:уникальность только внутри пакета. Соответствие формату не подтверждает правдивость данных.

Все команды проверяют общую revision в BEGIN IMMEDIATE,включая несвязанные правки. UUID requestKey глобально расходуется на отчёт/импорт и повтор отказывает,а не возвращает молчаливый успех. Preview/hash необязателен HTTP/не доказывает чтение человеком. Клиент не задаёт снимок/trace/output/owner/time. Ошибка оставляет ввод в форме;нужно явное обновление,автоматического слияния/повтора нет.

Архив цепочки/публикации закрывает новые прогоны;старый ready импортируется по снимку. Ready нельзя скрыть архивом до импорта;rejected/imported историю можно архивировать. Архив набора не отменяет его и не разрешает повтор. Нет отката импорта/отмены/повтора отдельного шага/полного промежуточного архива черновиков.

## Доказательства и границы

25 тестов: [результаты](docs/test-output.txt), [проверка](docs/verification.json), [браузер](docs/browser-proof.json), [источник](docs/reference-audit.md). Есть две SQLite-сессии,файловый перезапуск/согласованная SQLite backup,пустое восстановление/повреждённые копии,роли/Origin/CSRF/cookie и целый пакет.

Общая область всех сотрудников,не tenant-изоляция. Admin:цепочки/шаги/публикации/архив/копии;staff:прогоны/свой импорт. JSON/hash не подписаны:согласованность не подлинность/исторические права. Backup исключает users/auth/audit,restore только пустая область,HTTPJSON2МБ. Полную SQLite резервировать согласованно отдельно;несколько полных trace могут превысить лимит JSON восстановления. Нет UI сброса пароля/отзыва сессий.

Нет внешних коннекторов,HTTPendpointсекретов,AI/LLM/cron/webhook/n8ncode/реальных данных/сообщений/платежей. Локальный импорт не создаёт складской/клиентский/учебный результат. Нет публичного сервера,нагрузочного/полногоmobile/touch/screenreader/внешнего securityаудита. Свой код MIT;переиспользована собственная инфраструктура,предметные правила и UI отдельные. Подтверждённых клиентов/выручки нет.
